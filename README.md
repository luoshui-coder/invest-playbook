# 投资理财学习手册

一个面向零基础用户的静态学习网站，覆盖 LOF 基金套利、ETF 网格交易、港股打新与炒新、可转债打新。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

项目是纯静态 Vite 应用，`vercel.json` 已配置 `npm run build` 和 `dist` 输出目录，可直接部署到 Vercel。

## 风险提示

本网站仅用于投资学习和概念梳理，不构成任何投资建议、收益承诺或个性化资产配置方案。投资有风险，操作前应结合自身风险承受能力并独立判断。
